🎯 Cible de publication automatique

🪝 Webhook universel (le plus simple pour TikTok & Instagram)

Sans API compliquée : l'outil envoie la vidéo + la légende à votre scénario Make.com, Zapier ou n8n, qui publie ensuite sur TikTok, Instagram Reels, YouTube, LinkedIn…

  1. Créez un scénario sur make.com : déclencheur « Webhook personnalisé », puis module TikTok / Instagram / YouTube → Upload video.
  2. Collez l'URL du webhook ci-dessous, testez, activez. C'est tout.

▶️ YouTube (API officielle) …

  1. Sur console.cloud.google.com : créez un projet, activez YouTube Data API v3.
  2. Écran de consentement OAuth → « Externe », créez un identifiant OAuth → Application Web avec l'URI de redirection http://localhost:8099/.
  3. Téléchargez le JSON et placez-le ici : data/client_secrets.json.
  4. À la 1ʳᵉ publication, une fenêtre Google s'ouvre pour autoriser l'application. Les vidéos portant #Shorts sont classées Short automatiquement.

✋ Publication manuelle assistée (30 secondes chrono)

Bibliothèque → bouton 📋 Légende (copie titre + texte + hashtags) → ⬇️ (télécharge le MP4) → collez dans TikTok / Reels / Shorts depuis votre téléphone.

🍪 Accès à vos vidéos YouTube autorisées

Si YouTube demande une connexion pour une vidéo qui vous appartient ou vous est autorisée, choisissez un navigateur déjà connecté au compte qui y a accès.

  1. Sur votre PC : sélectionnez le navigateur connecté au compte qui a accès à cette source autorisée.
  2. N'utilisez pas cet accès pour contourner les restrictions de YouTube ou récupérer des vidéos de tiers.

📚 Enrichir le contenu

Ajoutez vos propres accroches / faits / astuces dans data/content_extra.json (même structure que la base, voir le README). Ils seront mélangés au contenu intégré sans rien coder.

Historique anti-répétition : data/used.json — supprimez-le pour réinitialiser la mémoire.
